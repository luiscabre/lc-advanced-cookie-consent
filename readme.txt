A configurable cookie consent and privacy preference manager for WordPress.

== Description ==

LC Advanced Cookie Consent is being developed to help WordPress site owners
manage cookie consent and visitor privacy preferences.

The initial release is under development. Features and compatibility
will be documented as they are implemented and tested.

== Installation ==

1. Upload the plugin to the WordPress plugins directory.
2. Activate LC Advanced Cookie Consent from the Plugins screen.
3. Configure the plugin when the settings interface becomes available.
